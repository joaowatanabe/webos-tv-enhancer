# webos-tv-enhancer

**English** · [Português](README.pt-BR.md)

An Apple TV-style launcher and a set of improvements for LG TVs running **webOS 6**: streaming Apple aerial wallpapers, weather, a dock that learns what you watch, and (on rooted TVs) a Gemini-powered voice assistant on the Magic Remote microphone.

> Independent project, not affiliated with or endorsed by LG Electronics. Brand names and logos belong to their owners and are used only as app shortcuts.

It started as a fork of [FreeMyTvWebOS](https://github.com/danielthejoker18/FreeMyTvWebOS) (MIT) and was rewritten from scratch.

## Tested on

- **LG OLED48C1PSA** (OLED C1 48"), **webOS 6.5.3** (firmware 03.53.45)
- Installed through LG Developer Mode with `@webos-tools/cli` from a Mac

It should work on other webOS 6 TVs (C1, G1, A1, etc.), but **there is no guarantee**: it has only been tested on the model above. Reports from other models are welcome in the issues.

## Features

| Feature | Needs root? |
|---|---|
| Wallpaper with 42 Apple aerial videos, streamed (0 MB on disk), category picker or OLED black | no |
| Streaming-only dock that learns your most-used app for each time of day | no |
| Weather via Open-Meteo (no API key): next hours and conditions | no |
| Quote of the day generated by Gemini (optional, free key) | no |
| Input row (HDMI, AirPlay), quick settings and installed apps | no |
| Pixel shift against burn-in | no |
| **Always open the launcher** (at boot and on the Home button), plus a "LG Home" button to go back to the stock home | **yes** |
| **Voice assistant** on the Magic Remote mic: answers questions (Gemini) and runs commands (open apps, play on YouTube, play on Spotify, volume, screen off) | **yes** |

## Requirements

- An LG TV with webOS 6 and the **Developer Mode** app enabled ([official guide](https://webostv.developer.lge.com/develop/getting-started/developer-mode-app)).
- On your computer: Node.js and LG's CLI:
  ```bash
  npm install -g @webos-tools/cli
  ares-setup-device   # register the TV; note the name you give it (e.g. mytv)
  ```
- Optional, for the root features: a rooted TV with the [Homebrew Channel](https://github.com/webosbrew/webos-homebrew-channel) ([webosbrew](https://www.webosbrew.org/)) and its elevated service. Rooting is at your own risk and is not covered here.

## Install

```bash
git clone https://github.com/joaowatanabe/webos-tv-enhancer.git
cd webos-tv-enhancer
cp .env.example .env                       # DEVICE=<TV name from ares-setup-device>
cp app/config.example.js app/config.js     # your personal config (git-ignored)
./scripts/deploy.sh                        # packages, installs and launches on the TV
```

When updating, bump `version` in `app/appinfo.json` first.

## Configuration

Edit `app/config.js`. Anything you leave out falls back to `app/config.example.js`:

```js
window.LAUNCHER_CONFIG = {
    name: 'Ana',
    city: { name: 'Curitiba', lat: -25.4284, lon: -49.2733, timezone: 'America/Sao_Paulo' },
    geminiKey: '',          // optional: https://aistudio.google.com/apikey
    spotifyClientId: '',    // optional (voice -> Spotify): https://developer.spotify.com/dashboard
    spotifyClientSecret: '',
    rootDaemon: false       // true only if the TV has root + Homebrew Channel
};
```

- **Dock:** copy the `dock` array from `config.example.js` and reorder or remove entries. Each app `id` comes from `ares-install --device <tv> --list`.
- **Inputs:** the `inputs` array defines the HDMI/AirPlay row, e.g. `{ icon: 'brand:playstation4', cap: 'PS5 · HDMI 2', app: 'com.webos.app.hdmi2' }`.
- **Gemini key:** optional, enables the quote of the day and the voice assistant. The key is bundled inside the `.ipk` installed on the TV (it is a client-side web app), so restrict it to the Generative Language API in Google Cloud.
- **Spotify:** optional. Create a free app in the Spotify dashboard and copy the Client ID and Secret. They are used only for search; playback happens in the TV's Spotify app.

## Root features

With a rooted TV, set `rootDaemon: true`. On first launch the app installs a small service (`app/system/fmtvd.sh`) in `/var/lib/webosbrew/` that runs at boot and:

- opens the launcher when the TV turns on and whenever the LG home appears (Home button, exiting an app);
- passes voice transcripts from the remote to the launcher (see below).

There is an anti-loop guard: at most 3 launches per minute. Details and uninstall steps are in [`docs/specs/001-home-daemon.md`](docs/specs/001-home-daemon.md).

### Voice assistant

Needs `rootDaemon: true` and a `geminiKey`. Hold the microphone button on the Magic Remote and speak. LG transcribes the audio, the `fmtvd` service hands the text to the launcher, and Gemini (function calling) decides what to do:

- **Question:** the answer shows in a ✦ bubble at the top of the screen.
- **Command:** open apps, play a video on YouTube, play music on Spotify (Web API + deep link, needs the Spotify keys), change volume, turn the screen off.

More in [`docs/specs/002-ia-no-controle.md`](docs/specs/002-ia-no-controle.md) (in Portuguese).

### Undo / get back to the stock home

- **Quick settings -> LG Home** goes back to the original home until you open another app.
- **Always open here: no** turns the behavior off for good.

## Remote controls

Arrows navigate, **OK** opens, **Back** goes up to the dock or closes the picker.

## webOS 6 limits (Chromium 79)

- No `backdrop-filter` over the video: the video runs on a hardware plane the blur cannot see, giving a black band and slowness.
- A single `<video>` element: two 2K videos decoding together are too heavy for the TV.
- No `cqw`, `aspect-ratio` or flexbox `gap`. The layout uses fixed px for 1920x1080.
- ES5 JavaScript and short shadows (large glows are expensive on every arrow press).

## Layout

```
app/
  index.html            the whole launcher (HTML + CSS + JS)
  config.example.js     default config (versioned)
  config.js             your config (git-ignored)
  system/fmtvd.sh       optional root service
  system/init.d-fmtv    Homebrew Channel boot hook
  assets/brands/        logos (sources in SOURCES.md)
scripts/deploy.sh
docs/roadmap.md, docs/specs/
```

## Roadmap

TV cleanup (factory apps, ads, telemetry; nothing is removed without explicit approval) and more video sources for the wallpaper. See [`docs/roadmap.md`](docs/roadmap.md).

## Security

- `app/config.js` and `.env` are git-ignored. Never commit keys.
- API keys end up inside the installed `.ipk`. Use restricted keys.
